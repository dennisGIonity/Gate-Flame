## 7. Security note

`GEMINI_API_KEY` must never be committed. It is supplied by AI Studio at runtime and,
for local work, kept in `.env.local` (git-ignored). Any key that reaches a public commit
must be rotated at <https://aistudio.google.com/apikey> immediately.
