Two numbers that look wrong and are not

11 devices vs 9. The filter counts 11 clients; the device list shows 9. The two extra are the box’s own interfaces. The list is filtered so a customer sees their household, not our plumbing.

Four devices set, none switched on. Shield regions have been chosen during testing but no tunnel is currently active — the picker works, nothing is routed through it right now.

What is still needed

In dependency order — each one has to land before the next can be attempted. The first four are what stand between this and a paying customer.

01
Blocks Play upload

Privacy notice and data-safety declaration

Shield state now leaves the box carrying device names and MAC addresses. POPIA s18 requires the privacy notice to say so, and Google Play’s data-safety form must declare device identifiers.

This was a deliberate trade, not an oversight — per-device Shield state is what lets support answer “which of my devices is on Japan?”. But the honest data-safety answer was a selling point, and it is a smaller one now.
02
Blocks Play upload

Signed release build

The keystore exists, but keystore.properties has never been written, so a release APK cannot be signed today. Play App Signing must be enrolled at first upload — it is the only recovery path if the upload key is lost.

Version numbers also disagree: tag v1.0.2 against VERSION_NAME 1.0.1. Play rejects a reused version code, so this has to be settled before the first upload rather than after.
03
Blocks first install

The customer’s own router step

The box works by being the router’s upstream DNS. Today that field is changed by hand. A customer needs one guided screen that makes the change and then re-reads the router to prove it took.

The credentialed router login is deliberately unbuilt. A router that reports “saved” without saving has already cost this household days — the guided flow must verify, not trust.
04

A second box, then a tenth

Everything above is measured on one appliance. The fleet console, per-box tokens and rollups are built for hundreds but have never seen two. 30-day and 90-day history are empty because the data does not exist yet.

Per-node auth would have broken every deployed box when it shipped — caught only because the test was written first. Scale assumptions stay unproven until a second box exists to disprove them.
05

Ionity’s own exit servers

Shield currently runs entirely on VPN Gate, a volunteer pool whose server list rotates and whose countries come and go. The control plane for Ionity-run exits is designed and unbuilt.

Live proof of the difference: the eight countries available right now are not the eight that were available this morning.
06

Support access to a customer’s box

The fleet console reads what each box reports and cannot reach into one. A persistent tunnel per box is the agreed direction; it does not exist yet.

Until it does, every diagnosis is limited to what the last check-in happened to contain — which is why the support view names the field each finding came from.
07

Self-hosted fonts on the console

The wall console deliberately loads no remote fonts, so it falls back to system faces. Shipping the three families locally finishes the look without sending a request off the LAN.

Small, but it is the one place the console visibly differs from the design — on a product whose promise is that almost nothing leaves the house.
