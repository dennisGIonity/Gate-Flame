01

Prove the release keystore actually opens

Critical 5 min No recovery path

The file meant to hold your signing certificate’s details — ~/.gateflame-signing/cert-info.txt — instead contains this:

keytool error: java.io.IOException: Keystore was tampered
with, or password was incorrect
Caused by: java.security.UnrecoverableKeyException:
        Password verification failed

So the keystore’s usability has never actually been demonstrated. It was created on 29 Aug; the verification step either failed or was run with the wrong password, and the error was saved where the certificate should be.

  1. Open a terminal and run the check yourself: 
    keytool -list -v -keystore "$env:USERPROFILE\.gateflame-signing\gateflame-release.jks"
  2. Enter the keystore password when prompted.
Proof it worked

You see Alias name:, Valid from: and a SHA-256 fingerprint. If you see the same “password was incorrect” error, the key is either lost or the password you have is wrong — tell me immediately and do not build anything with it until we know which.

This is first because every other Play task depends on it, and because it is the one asset that cannot be regenerated. A key you cannot open is the same as no key — you would find out at first upload, after committing to a listing.

07

Tell the box which interface is the WAN

2 minClears the only open support finding

This is the single item the fleet console currently flags on your node. Data-cap reporting is unavailable until it is set. The box deliberately does not guess — guessing wrong bills LAN traffic against a customer’s cap.

  1. On the Pi: 
    sudo systemctl edit gateflame-node-agent
  2. Add, in the editor that opens: 
    [Service]
Environment=GATEFLAME_WAN_INTERFACES=eth0
  3. Then: 
    sudo systemctl daemon-reload
sudo systemctl restart gateflame-node-agent
Proof it worked

Refresh the fleet console’s Support view for GF-72TYTITQ. The “WAN audit is degraded” finding should be gone, leaving zero findings. If it persists, eth0 is the wrong interface name for that box.
